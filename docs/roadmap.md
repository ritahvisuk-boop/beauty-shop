# План розробки проєкту Beauty Shop (Roadmap)

## Загальна мета

Метою подальшої розробки Beauty Shop є розширення функціональності онлайн-магазину косметики. Протягом найближчих чотирьох тижнів планується вдосконалити каталог товарів, додати нові можливості для користувачів та реалізувати основні функції керування магазином.

## Тиждень 1. Розширення каталогу товарів

Планується доповнити базу даних інформацією про косметичні товари, зокрема додати ціну та опис. Також передбачається створити новий API-ендпоінт для отримання детальної інформації про окремий товар.

Очікуваний результат - користувачі зможуть переглядати детальну інформацію про косметичну продукцію.

## Тиждень 2. Пошук товарів

Планується реалізувати пошук косметичних товарів за назвою. Для цього буде додано поле пошуку на сторінці магазину.

Очікуваний результат - користувачі зможуть швидко знаходити потрібні товари в каталозі.

## Тиждень 3. Базова авторизація

Планується додати можливість входу адміністратора до системи за допомогою логіна та пароля. Функції керування товарами будуть доступні лише після авторизації.

Очікуваний результат - адміністратор матиме окремий доступ до керування магазином.

## Тиждень 4. Керування товарами (CRUD)

Планується реалізувати можливість додавання нових товарів, редагування їхньої інформації та видалення з бази даних.

Очікуваний результат - адміністратор зможе самостійно оновлювати асортимент косметичних товарів.

## Підсумок

Протягом чотирьох тижнів планується поступово вдосконалити Beauty Shop, зробити каталог інформативнішим і зручнішим для покупців, а також додати базові можливості адміністрування магазину.
